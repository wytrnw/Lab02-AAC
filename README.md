В моём эксперименте Release оказался быстрее Debug примерно в ___ раза.

Что я обнаружила при сравнении IL:
- в Debug присутствуют инструкции nop, которых нет в Release;
- в Debug у Add() есть блок .locals init с двумя переменными (result, b)
и пара stloc.0/ldloc.0;в Release остались только ldarg.0, ldarg.1, add, ret;
- количество IL-инструкций в методе Add() изменилось с 9 до 4,в методе SumTo() — с 27 до 20;
- размер кода метода Add() уменьшился с 12 до 4 байт;
- в Debug условие цикла SumTo() — четыре инструкции (cgt, stloc.2,
ldloc.2, brtrue.s), в Release — одна: ble.s.
